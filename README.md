# cpp-calc

一个用 C++ 实现的小型表达式计算器: 读取一行**中缀表达式**,转换成**前缀表达式(波兰表达式)**,
再用栈求值

## 功能

- 支持加,减,乘,除 `+ - * /`
- 支持括号 `( )`
- 支持多位数(如 `123 + 45`)
- 自动忽略空格,制表符,换行等空白字符
- 输出转换后的前缀表达式,以及计算结果

## 构建与运行(Windows)

### 方式一: MinGW / g++

```bat
g++ -std=c++17 -O2 -o calc.exe main.cpp
calc.exe
```

### 方式二: MSVC

```bat
cl /EHsc /std:c++17 main.cpp
main.exe
```

```bat

```

MinGW 默认安装路径通常是 `C:\mingw64\bin`(或 Dev-C++ 自带的 `...\MinGW64\bin`)

## 使用示例

输入: 

```text
(1 + 2) * 3 - 4
```

输出: 

```text
- * + 1 2 3 4
5
```

第一行是前缀表达式(数字和运算符之间用空格分隔),第二行是计算结果

更多例子: 

| 中缀输入 | 前缀输出 | 结果 |
|---|---|---|
| `1+2*3` | `+ 1 * 2 3` | `7` |
| `(1+2)*3` | `* + 1 2 3` | `9` |
| `8/2-1` | `- / 8 2 1` | `3` |
| `1-2-3` | `- - 1 2 3` | `-4` |
| `2*(3+4)*5` | `* 2 * + 3 4 5` | `70` |

## 实现原理

### 1. 预处理: 去空白

`transform` 去掉所有 `isspace` 字符,得到紧凑字符串

### 2. 分词

`tokenize` 把字符串切成 `vector<string>`: 连续数字合并成一个 token,其余字符各自成为一个
token(`+ - * / ( )`)

### 3. 中缀 → 前缀

`toPrefix` 采用**从右往左扫描 + 运算符栈**的算法: 

| 读到 | 动作 |
|---|---|
| 数字 | 直接输出 |
| `)` | 入栈 |
| `(` | 弹栈并输出,直到遇到 `)`,再把 `)` 弹掉 |
| 运算符 | 弹掉栈中**优先级严格更高**的运算符并输出,然后自己入栈 |
| 扫描结束 | 弹空栈,输出的逆序即为前缀式 |

- **最后 `reverse`**因为是从右往左扫,输出自然是倒序的,必须翻转才是真正的前缀式

### 4. 前缀求值

`calc` 用**从右往左扫描 + 值栈**的迭代方式求值: 

- 遇数字: `stoi` 后入栈
- 遇运算符: 弹两个数,**先弹出的是左操作数**,计算 `x op y` 后压回

以 `- * + 1 2 3 4` 为例: 

| 步骤 | 读到 | 栈(底 → 顶) |
|---|---|---|
| 1 | `4` | 4 |
| 2 | `3` | 4, 3 |
| 3 | `2` | 4, 3, 2 |
| 4 | `1` | 4, 3, 2, 1 |
| 5 | `+` | 4, 3, 3(= 1+2) |
| 6 | `*` | 4, 9(= 3*3) |
| 7 | `-` | 5(= 9-4) |

## 代码结构

| 名称 | 作用 |
|---|---|
| `ops` | 运算符 → 优先级 的映射表(`* /` 为 2,`+ -` 为 1) |
| `prec` | 查询优先级,未知符号返回 0 |
| `isOp` | 判断 token 是否为已支持的运算符 |
| `transform` | lambda,去除空白字符 |
| `tokenize` | lambda,字符串切分为 token 列表 |
| `toPrefix` | lambda,中缀 token 列表 → 前缀 token 列表 |
| `calc` | lambda,前缀 token 列表 → 整数结果 |

## 限制

- **只支持整数**
- **不支持一元负号/正号**
- **不支持幂运算 `^`**
- **没有输入校验**
- **只读一行,只算一次**
- **int 溢出**
- ......
